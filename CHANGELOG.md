# Changelog

Все значимые изменения в проекте F1 Service.

## [0.5.0] - 2026-07-16

### Добавлено
- Предзагрузка результатов сессий
- Предзагрузка таблиц пилотов и конструкторов

### Изменено
- Улучшено оформление сообщения календаря  

---

## [0.4.0] - 2026-06-26

### Добавлено
- Динамическая настройка оповещений (можно выбрать о каких сессиях напоминать и за какое время)

---

## [0.3.0] - 2026-06-13

### Добавлено
- API слой на Django Ninja.
- Асинхронный HTTP клиент для бота.
- Оповещения о гоночных сессиях за 1 час до начала (celery).

### Изменено
- Бот полностью отвязан от бэкенда и работает только через API.
- Сервисы переведены на асинхронное взаимодействие с БД.

### Исправлено
- Устранены async/sync конфликты.
- Исправлена утечка HTTP сессии.
- В результатах гонки None заменён на DNF.

---

## [0.2.0] - 2026-05-02

### Добавлено
- Redis для кэширования данных.
- Асинхронные HTTP-запросы через aiohttp.
- Retry-механизм для повторных попыток запросов.
- Docker Compose для локальной разработки с Redis.

### Изменено
- Внешние API-запросы переведены на асинхронное выполнение.
- Добавлено кэширование данных OpenF1 API.

---

## [0.1.0] - 2026-04-09

### Добавлено
- MVP версии F1 Service.
- Telegram-бот на Aiogram.
- Интеграция с OpenF1 API.
- Календарь гонок и результаты заездов.
- Чемпионаты пилотов и конструкторов.
- Поддержка пользовательских часовых поясов.
- PostgreSQL в качестве основной базы данных.
- Docker Compose для запуска проекта.
- Nginx для проксирования запросов и обслуживания статики.

# F1 Service 🏎️ 

Сервис для фанатов формулы 1. Предоставляет актуальную информацию о календаре, гонках, результатах, чемпионатах, пилотах и командах.

## 🏁 О проекте

**Статус:** MVP (Minimum Viable Product)

backend-приложение на Django с интегрированным Telegram-ботом (aiogram), которое предоставляет пользователю актуальную информацию о Формуле 1.

## ⚙️ Технологии
- Python
- Django
- Aiogram
- PostgreSQL
- Redis
- Docker
- Nginx
- Gunicorn

## 🛠 Основной функционал

- **Календарь** — полный календарь сезона
- **Оставшиеся гонки** — только предстоящие этапы
- **Следующая гонка** — детальное расписание ближайшего Гран-при с учётом часового пояса пользователя
- **Список пилотов** — все пилоты сезона с номерами
- **Список команд** — все конструкторы сезона
- **Результаты** — результаты завершённых сессий (FP1, FP2, FP3, квалификация, спринт, гонка) по выбору пользователя
- **Чемпионат пилотов** — актуальная турнирная таблица пилотов
- **Чемпионат команд** — актуальный Кубок конструкторов

## 🗺 Планы по развитию

- **Оповещения (Celery)** — напоминание пользователям о начале сессий
- **История результатов** — просмотр результатов любых прошедших Гран-при
- **Детальная информация** — возможность получать подробную информацию о трассах, командах, пилотах, сезонах
- **Тестирование** — unit тесты
- **Мультиязычность** — перевести интерфейс на несколько популярных языков

## 🔐 Админ-панель Django

Доступна по адресу `/admin` после запуска backend-сервера.

- Управление Гран-при (даты, время сессий, указание спринт уикенда)
- Редактирование пилотов и команд
- Редактирование информации о трассах
